# MCP Template — краткое руководство

## Что это

Мини-шаблон MCP-сервера на `FastMCP`: тулы, ресурсы, промпты и точка входа.

## Структура

```
template/
  tools/       # ваши наборы тулов (каталоги с toolset.py)
  resources/   # публикуемые ресурсы по URI
  prompts/     # текстовые шаблоны именованные промпты
  main.py      # регистрация тулов + mcp.run()
```

Если точнее:

* `tools/` — `@mcp.tool(...)`: вызываемые функции.
* `resources/` — `@mcp.resource("scheme://{...}")`: публикуемые ресурсы по URI (для крупных/долгоживущих результатов).
* `prompts/` — `@mcp.prompts`: регистрируемые именованные промпты (шаблоны/сниппеты).

## Как добавить тул

1. Скопируйте папку `template/` и вставьте ее в рабочую папку `mcp_server`.
2. Реализуйте свои тулы, промпты, ресурсы.
3. Добавьте в `pyproject.toml` необходимые библиотеки.

## Добавление дополнительных библиотек

В проекте для каждого mcp сервера необоходимые библиотеки добавляются в extras:

```toml
# pyproject.toml
[project.optional-dependencies]
...

{{mcp_name}} = [
    "pandas=0.1.0",
    "matplotlib=0.2.0"
]
```

Благодаря этому вы можете работать локально с окружением только для своего тула:

```bash
uv sync --extra {{mcp_name}}

# или установить все
uv sync --all-extras
```

## Настройка mcpo

Добавьте в конфиг команду запуска вашего `{{mcp_name}}` в файл `mcpo.config.json`:

```json
{
  "servers": {
        # ...
        "{{mcp_name}}": {
            "type": "streamable-http",
            "url": "http://0.0.0.0:8001" # адрес сервера внутри докер сети
        }
  }
}
```

## Тесты

Чтобы добавить тесты к своим тулам, создайте папку:

```
tests/{{mcp_name}}/
```

и кладите туда `test_*.py`.
